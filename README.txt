AMIR AREB PORTFOLIO

Pages included:
- index.html   (Home)
- about.html   (About)
- skills.html  (Skills)
- projects.html (Projects)
- contact.html (Contact)

HOW TO PREVIEW
Open index.html in a browser. All pages share styles.css and nav.js.

BEFORE PUBLISHING
1. In contact.html, replace your-email@example.com with your real email address (both visible text and the JavaScript 'to' value).
2. Replace the GitHub and LinkedIn placeholder links with your real profile URLs.
3. Replace the Instagram and Telegram placeholder usernames in contact.html with your real usernames.
4. Update project descriptions or add live project URLs when available.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository named amirareb.github.io (or use your existing Pages repository).
2. Upload all files and the assets folder, keeping the folder structure unchanged.
3. In repository Settings > Pages, select Deploy from a branch and choose main / root.
4. Your site will be available at https://amirareb.github.io/ after GitHub Pages finishes publishing.
